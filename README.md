# TMA3084_102942_Lab-1
**TMA3084 SELab Lab 1 - Pizza Order Calculator
**
**Description**
This project is a simple Pizza Order Calculator developed using Dart. It allows users to select a pizza size, enter the quantity, and calculate the total payment.

**Pizza Prices**
- Small: 5 USD
- Medium: 7 USD
- Large: 10 USD

**Features**
- Accepts the pizza size from the user.
- Accepts the quantity of pizzas.
- Calculates the total payment.
- Allows users to place another order.

**How to Run**
1. Install the Dart SDK.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command: dart pizza.dart
